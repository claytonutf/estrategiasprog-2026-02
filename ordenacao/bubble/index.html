O que é ordenação?

Ordenar é o ato de colocar um conjunto de dados em uma ordem predefinida. A ordenação permite que o acesso aos dados seja feito de forma mais eficiente.

A ordenação é feita com base em uma chave: o campo do item usado na comparação, que define se um elemento vem antes ou depois de outro no conjunto ordenado. Qualquer tipo de chave pode ser usado, desde que exista uma regra de ordenação bem definida.

Tipo de chave

Numérica — 1, 2, 3, 4, 5
Lexicográfica (ordem alfabética) — Ana, André, Bianca, Ricardo

Direção

Crescente — 1, 2, 3, 4, 5
Decrescente — 5, 4, 3, 2, 1

Ordenação interna e externa

Os algoritmos de ordenação também se classificam pela forma como acessam os dados durante o processo.

Interna (in-place)

O conjunto de dados cabe inteiro na memória principal. Qualquer elemento pode ser acessado imediatamente — é o caso do bubble sort.

Externa

O conjunto não cabe na memória principal e fica em memória secundária (por exemplo, um arquivo). Os elementos são acessados sequencialmente ou em blocos.

Estabilidade

Um algoritmo é estável quando a ordem relativa de elementos com chaves iguais não muda durante a ordenação.

Bubble sort — ordenação por “bolha”

O nome remete a bolhas flutuando na água em direção ao topo, até encontrarem seu próprio nível — o que corresponde à ordenação crescente.

A cada passagem, o algoritmo compara pares de valores em posições consecutivas do array e os troca quando estão fora de ordem. Isso empurra, uma posição por vez, o maior valor da porção ainda não ordenada até seu lugar correto. Repetindo esse processo, o array inteiro é ordenado.

Método bubble sort em C
01void bubbleSort(int *V, int N){
02  int i, continua, aux, fim = N;
03  do{
04    continua = 0;
05    for(i = 0; i < fim-1; i++){
06      if(V[i] > V[i+1]
07      {aux = V[i];
08       V[i] = V[i+1];
09       V[i+1] = aux;
10       continua = i;
11      }
12    }
13    fim--;
14  }while(continua != 0);
15}

O do-while encerra quando continua permanece igual a zero — ou seja, quando uma passagem inteira não realiza nenhuma troca (linha 4 zera a variável; a linha 10 a atualiza a cada troca). Essa verificação permite encerrar o algoritmo mais cedo se o array já estiver ordenado. A variável fim diminui a cada passagem (linha 13), já que o maior valor de cada rodada já está no seu lugar e não precisa mais ser comparado.

Veja o algoritmo em ação

Cada passagem compara pares vizinhos, troca os que estão fora de ordem e "empurra" o maior valor da rodada até sua posição final — como uma bolha subindo até seu nível.

Custo do algoritmo

O bubble sort é simples de entender e implementar, mas sua eficiência cai rapidamente à medida que o número de elementos cresce — por isso não é recomendado para grandes volumes de dados. Considerando um array com N elementos:

O(N)
Melhor caso — array já ordenado
O(N²)
Caso médio
O(N²)
Pior caso — array em ordem inversa
